# Local Aider Kit

A Windows bootstrapper for Aider + Ollama using a local, abliterated Qwen model.
No cloud API key is required. Model downloads happen separately during setup.

## Install
Run LocalAiderKit-Setup.exe, or run:
powershell -ExecutionPolicy Bypass -File .\setup.ps1

## Launch
Run launch.bat. Open a project folder first if you want Aider to work there.

## Requirements
Windows 10/11 x64, internet for initial downloads, sufficient RAM/disk space.
GPU acceleration depends on your hardware. The model is not bundled in the EXE.
